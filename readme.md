## 🔧 Como adicionar questões

1. Crie a pasta: `faseN/disciplina/`
2. Nomeie o arquivo: `questao-NN.ext`
3. Adicione a linha na tabela correspondente
4. Se a disciplina não existe, crie a seção `###` sob a fase correta
